## 📖 使用指南

### 1️⃣ 备份模式

**操作步骤：**
1. 点击侧边栏 **"📤 备份"** 进入备份模式
2. 点击 **"选择文件夹"** 选择要备份的源文件夹
3. 选择同步类型：
   - **差异同步**：仅备份新增或修改的文件
   - **全量同步**：备份所有文件
4. 点击 **"开始备份"** 
5. 备份包将生成在 `backups/` 文件夹中

**优势：**
- ⚡ 差异同步速度快，节省空间
- 🔒 自动MD5校验，确保数据完整性
- 📋 生成清单文件，记录所有变更

### 2️⃣ 同步模式

**操作步骤：**
1. 点击侧边栏 **"🔄 同步"** 进入同步模式
2. 选择已生成的备份包
3. 点击 **"选择同步目标文件夹"**
4. 点击 **"开始同步"**
5. 系统将自动处理：
   - ✅ 无冲突文件：直接同步
   - ⚠️ 冲突文件：移至差异文件夹

**冲突处理逻辑：**
- **A端更新，B端未变**：直接覆盖 ✓
- **B端更新，A端未变**：移至差异文件夹 →
- **双方都更新**：移至差异文件夹，人工比对 →

### 3️⃣ 数据分析

#### 📈 备份趋势分析
- **热力图展示**：类GitHub活跃度图表
- **维度切换**：支持日/周/月/年视图
- **悬停详情**：显示每日备份文件数

#### 💾 存储空间分析
- **Treemap可视化**：直观展示各文件夹占用
- **详细列表**：点击右上角查看完整统计
- **容量排序**：快速定位大文件夹

### 4️⃣ 设置中心

- **主题切换**：明亮/暗黑模式一键切换
- **数据管理**：查看和清理历史记录
- **工具提示**：详细的使用说明

## 🛠️ 技术架构

### 核心模块

```
tools_sync/
├── gui_qt6.py          # PyQt6现代化图形界面
├── sync_core.py        # 同步引擎（差异检测、打包）
├── file_scanner.py     # 文件扫描与MD5计算
├── database.py         # SQLite数据持久化
├── treemap_widget.py   # Treemap可视化组件
└── requirements.txt    # 依赖管理
```

### 技术栈

| 技术 | 用途 |
|------|------|
| **PyQt6** | 跨平台GUI框架 |
| **SQLite** | 本地数据存储 |
| **MD5哈希** | 文件完整性校验 |
| **ThreadPoolExecutor** | 并发文件处理 |
| **Zipfile** | 压缩包管理 |

### 核心算法

**差异检测算法：**
```
1. 扫描源文件夹，计算所有文件的MD5
2. 与数据库中的历史记录对比
3. 标记新增、修改、删除的文件
4. 仅打包变更文件
```

**冲突检测算法：**
```
1. 计算源文件（A端）MD5
2. 计算目标文件（B端）MD5
3. 查询数据库中的历史MD5
4. 三方比对确定冲突类型
5. 自动归档或覆盖
```

## ❓ 常见问题

### Q1: 差异同步和全量同步有什么区别？
**A**: 
- **差异同步**：只备份新增或修改的文件，速度快，节省空间
- **全量同步**：备份所有文件，适合定期完整归档

### Q2: 如何处理冲突文件？
**A**: 冲突文件会被移动到 `差异文件/` 文件夹，保留时间戳，您可以手动比对后决定保留哪个版本。

### Q3: 备份包存储在哪里？
**A**: 默认存储在应用程序同目录的 `backups/` 文件夹中。

### Q4: 支持哪些文件类型？
**A**: 支持所有文件类型，无限制。

### Q5: 可以自定义备份目录吗？
**A**: 当前版本默认使用 `backups/` 文件夹，后续版本将支持自定义。
